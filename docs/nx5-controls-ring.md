# Controls 百分比圆环修复

2026-10-13，确认 Controls 状态圆环没有随百分比变化：原实现只是 `68×68`、`9px` 边框的完整圆，只有中心文字绑定 `level`，开关只改变边框颜色。主机负对照在 0% 得到 100% 着色覆盖，明确复现此问题。

`0e8516d` 改为顶部起顺时针的原生 Slint 环形扇区。0% 仅显示底轨，100% 使用完整圆边框，避免首尾重合的弧线退化。关闭输出时保留配置进度并显示灰色；下方 Meter 仍显示零输出。修改限于展示界面及其回归、说明，Slint/桥接库/TDE/SDK 本轮均未修改。
