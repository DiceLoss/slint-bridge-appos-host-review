# X9 改动后的 NX5 链路回归

2026-10-15，在 NX5 / Linux `4.9.138 #233` 上验证 X9 接入及性能优化是否影响原 NX5 链路。旧部署为桥接库 `2fddc04`、Slint `9a1a3b1`；当前实现为桥接库 `cacf98f`（本次开始的仓库 HEAD 为文档提交 `99d7da5`）、Slint `fa6a6d0`。当前 0° NX5 TDE 链路未发现功能退化；性能接近，横向本轮少 0.19 FPS，资源窗口 RSS 约多 0.16 MiB。完成契约、像素判据和设备准入均保持原标准。

## 代码影响范围

| 改动 | NX5 是否会经过 | 本轮核验 |
| --- | --- | --- |
| X9 DRM 完成事件、控制台与固件准入 | 不会；仅 `fbdev` 编译 | feature 互斥、NX5 板级分派 |
| `validate_layout` 改为携带 fd 的闭包 | 会；NX5 忽略新 fd 参数，仍调用原验证函数 | 初始化、实际布局与退出资源 |
| 通用不透明 BGRA 行转换 | NX5 的 alpha 量程为 128，新增量程 255 条件不成立；ARM `nx5-tde` 更早进入原 NEON 转换 | ARM 边界、透明/半透明/不透明真实写页 |
| evdev 增加能力查询与 Type-A 分支 | 能力查询会执行；NX5 `gsl1686` 仍选择 ABS_X/Y + BTN_TOUCH | 主机丢包/协议回归及设备 evdev 注入 |
| Slint 旋转截图、SVG 栅格尺寸与纹理分块 | 共用依赖；本机默认 0° 不进入 90°/270° 分块 | 主机四方向像素回归、设备 TDE/软件回退与界面检查 |

NX5 的阻塞 PAN 完成回调、SDK 会话持有、TDE 原生实现和调度逻辑没有因 X9 改动而替换。仍只有两张物理页、至多一笔在途提交和一帧预渲染，完成确认前不写任一物理页。

## 主机与独占实机回归

主机 feature 矩阵（`fbdev`、`nx5`、`nx5-tde`）、格式检查、`nx5-tde,slint/mcp` 全 target 严格 clippy、原生 TDE 故障注入/像素转换/SDK 会话检查通过。当前 ARM `nx5-tde` 测试程序和 `showcase` 交叉构建通过。

设备身份重新核对：USB1 root 与 ADB `192.168.1.151:5555` 的启动 ID 均为 `4aa4f5d2-8de2-42cb-9c2b-44c3e74d6e2b`，MAC `f6:1e:04:4c:d8:78`；旧常驻路径和 SHA256 与保留记录一致。旧显示所有者退出且 VO/MMZ 恢复基线后，逐项独占运行：

| 用例 | 结果 |
| --- | --- |
| `neon_writeback_boundaries` | 全通道/alpha、量程 128/255、长度 0–65、偏移 0–3 和保护区精确一致 |
| `nx5_hardware_compare` | 真实 TDE 复制/混合、缓存、源裁剪、奇数边缘、软件回退、注入的提交前错误通过；RGB 最大允许差保持 1 |
| `nx5_demo_pages_match_full_frames` | 真实 TDE 绘制、100 帧内存双页与独立整帧参考通过，超差通道为 0；此项不写物理页 |
| `budgeted_shared_mmz_writeback_preserves_pixels` | 6 帧透明度序列，每帧 75 次分段；当前前台及源画布保持不变，完成页像素精确一致 |
| `shared_mmz_writeback_matches_staged_pixels` | 210 次真实提交，0/127/255 三档 alpha；抽取的两条写页路径结果精确一致 |
| `blocking_flip_cadence` | 128 次翻页；剔除 8 次预热后均值 34.480 ms，29.003 FPS |

六项均正常退出，每项之后 VO 关闭、MMZ 恢复 **4900 KiB / 2 块**。当前真实共享画布写页均值约为全透明 6.13 ms、半透明 19.19 ms、不透明 6.56 ms；这些是本轮阶段样本，不代替完整应用吞吐。

## 新旧应用对照

在同一次启动上，先后运行旧版与当前版。每个版本分别使用无 trace 的资源进程和启用原有提交统计的 FPS 进程；均以有限定时正常退出，使用同一字体、SDK、1024×600 / 0° 布局和设备路径。

每轴先在列表中段预热至少 8 秒，无 trace 资源窗口至少 45 秒，独立 FPS 动作窗口至少 60 秒。手势检查真实位移、轴锁定、端点和误选；采样期间不截图或录制输入。FPS 只使用完整的 150 次成功提交批次，丢弃跨开始边界的首批；不是 UI ticks 或 TDE 调用次数。

当前资源结果：纵向 CPU 78.83% → 78.94%、RSS 18.00 → 18.16 MiB；横向 86.19% → 86.24%、18.26 → 18.42 MiB。CPU 采用单核 100% 口径，RSS 均值增加约 164/166 KiB；两轴均为 3 个线程，MMZ 均为 12760 KiB / 6 块。资源有效窗口分别为旧版 46.58/47.07 秒、当前版 45.29/47.45 秒。

| 场景 | 旧版 → 当前 FPS | 变化 | 旧版 → 当前 CPU | 旧版 → 当前平均 RSS |
| --- | ---: | ---: | ---: | ---: |
| 富列表纵向 | 27.46 → 27.52 | +0.22% | 78.83% → 78.94% | 18.00 → 18.16 MiB |
| 富列表横向 | 26.03 → 25.84 | −0.71% | 86.19% → 86.24% | 18.26 → 18.42 MiB |

每个 FPS 方向使用 10 个完整批次、1,500 次完成提交，共 6,000 次；旧版动作窗口 61.37/64.57 秒，当前版 60.81/65.12 秒。总体吞吐接近，横向本轮低约 0.19 FPS，不能写成完全零性能影响，也不能用单轮窗口判定长期抖动或稳定的微小性能差异。

四个性能进程均正常退出，VO 关闭、MMZ 回到 4900 KiB / 2 块。主表 CPU/RSS 只取无 trace 窗口；trace 进程的 RSS 差异方向与其不同，不将约 0.16 MiB 的单次差异归因于某个新分配。没有新增画布、物理页或 MMZ 块。

## 界面、输入与收尾

当前版在两种富列表奇数位置读取完整前台页：纵向首项 y=185、pan=0,0；横向首项 x=197、pan=0,600。共 **1,228,800 像素**与当前同板原生软件截图最大通道差 1、超差像素 0，物理 alpha 全部精确为 128；同时与 `2fddc04` 的既有同状态物理页档案逐字节一致。旧像素档案来自 [上一轮最终验证](nx5-rich-render.md)，本轮重新采集的是当前版，未将历史文件说成新采样。

八页主体检查已完成，包含表单、键盘/弹窗、透明窗口、PNG/SVG 四档缩放、富列表双向宽幅拖动和交互记录。首次 190 秒有限窗口在末尾普通设备列表边界检查中到期，应用正常退出为 0、VO/MMZ 释放正常；MCP 客户端因此收到连接关闭。保留不完整日志，并在新进程单独补跑双向边界、18 项覆盖、稳定 ID 选择和过滤。

边界复测通过：18 项均被访问，左右边界夹紧、拖动不误选、末项选择和筛选/清空均通过。八页主体录制有 743 条事件，零丢失、零未知事件；两次 UI 进程共保存 21 张受内存检查保护的过程截图（包含重复边界起点），另有两张物理页软件参考。首次不完整客户端退出保留原日志，不计为一次全套通过。

随后对真实 `/dev/input/event0` 注入 ABS_X/Y、BTN_TOUCH、SYN_REPORT：两次点击与一次 12 步拖动。Slint 记录 21 条事件，3 次接触的 6 个按下/释放边沿全部 Accepted，坐标误差小于 1 像素，点击/拖动计数分别增加 2/1，丢失与未知事件均为 0。这覆盖内核 evdev 到应用处理；未把自动注入当作手指或传感器时延验证。

测试完成后已恢复原 `2fddc04` + Slint `9a1a3b1` 的正式常驻程序，观测 PID **22711**，原 ELF 摘要未变；Controls 48%、富列表纵向起点、无选中项，无退出定时器、trace、WBC 或临时探针。常驻 RSS / VmHWM 为 18444 KiB、3 线程，MMZ 12760 KiB / 6 块，归档后 MemAvailable 为 38796 KiB。原恢复版本 `1225593` 也保持完整。

六项硬件和六个有限应用进程均正常退出，资源恢复基线；测试开始后的 148 行新增非空内核记录没有 OOM 或强制 MMZ/VO 回收。原始 dmesg 的终端空行差异在比对时忽略，原始字节档案保留。恢复时首次直接执行未带执行位的启动脚本被 shell 拒绝，随后使用原有 `sh start.sh` 方式成功启动；失败尝试单独存档，未修改脚本权限或程序。

硬件测试、像素采样和收尾事务分别校验归档 39、4、66 个临时文件后清理；当前候选 ELF 已归档移除，本轮没有把它设为 NX5 默认常驻。当前状态见 [设备快照](../test-app/devices/nx5/current-target.json)。

原始证据保存在本地忽略目录 `evidence/nx5-x9-regression/2026-10-15/`，检出仓库需另行取得。本轮不操作 X9 当前常驻程序，不把 MCP 截图当作 TDE、物理页或面板扫描证明。本轮没有新增 WBC/非黑色视频底层、实体手指、面板逐扫描帧或 NX5 90°/270° 实机测试；结论限定当前 `nx5-tde`、1024×600、0° 部署。
