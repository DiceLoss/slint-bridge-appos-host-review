本篇合并启动、退出、输入、界面及物理页验证，按原提交和日期保留结论。性能数据集中在 [NX5 性能记录](nx5-performance.md)，显示完成与 WBC 合成边界见 [显示调查](nx5-display.md)。本次整理不构成任何新实机验证。

当前操作入口为 [设备说明](../test-app/devices/nx5/README.md) 和 [工具说明](../test-app/tools/nx5/README.md)。原始 `evidence/` 不随 Git 分发；历史的失败、跳过和信号退出记录不改写为成功。

## 初次完整退出失败

2026-10-11，`2cd98fa` 的 TDE 像素、100 帧内存双页、128 次翻页、300 帧 WBC 正对照、30 帧混色负对照及 60 秒纹理运行通过；但完整显示进程退出时三块 TDE MMZ 仍由内核强制回收。EIO 发生后等待 WBC 清理的行为通过，不能据此掩盖平台/TDE 未析构。

该失败后来修复，但仍属于原版本结果。证据：`evidence/nx5-regression/2026-10-11-2cd98fa/`。

<a id="nx5-tde-exit"></a>

## 引用环与 EIO 清理修复

`177c18a` 修复平台/窗口强引用环，并在等待提交完成后隐藏错误返回路径中的窗口。仅弱化窗口引用只能修好正常退出，EIO 仍失败；完整修复才使两者通过。清理顺序为等待提交、释放 TDE、释放 SDK，再解除 framebuffer 映射；未知 DMA 保留策略不变。

实机正常退出两轮各 300 个 WBC 样本，EIO 两轮各 600 个样本，均无混色；EIO 后仍等待约 19.65 / 19.74 秒完成 WBC 清理。TDE/100 帧双页/翻页三项通过，稳定纹理批次 29 FPS。SDK 的 `Force to close voDev(0)` 与 TDE `MMB LEAK` 分别判读。首次 show 失败和延迟创建的后续缺陷不计为本版本已经覆盖。

证据：`evidence/nx5-tde-exit/2026-10-11/`，包括原实现、只弱化引用及完整修复的红/绿回归。

另有 300 帧 WBC 正对照和 60 秒纹理运行通过；三项独立硬件测试未在该轮重跑。证据：`evidence/nx5-startup/2026-10-11-949ceb9/`。

## 自定义路径和共享 SDK 加载

2026-10-12，`c03c3bb` 通过自定义 framebuffer/触摸链接访问真实设备，ioctl 读到 1024×600、stride 4096、双页 4915200 字节；两页各 614400 像素正确。同一组件两次拒绝超宽窗口后能恢复。

证据：`evidence/nx5-configured-paths/2026-10-12-c03c3bb/`。

<a id="nx5-review-fixes"></a>

## SDK 重试和预渲染帧清理

2026-10-12，`bccf6b9` 修复 VO 引用不配对、重复运行先提交旧预渲染帧、锁竞争错误分类三个问题。构造函数已有 VO 引用由会话接管；库映像驻留复用 SDK 描述符缓存；退出丢弃未提交预渲染帧，同时保留修复两页所需脏区。未知 DMA 同时保留 SDK 会话和独占锁。

两次 framebuffer 初始化失败、两次输入失败和成功运行后的 UI 线程退出均释放 VO/TDE，描述符没有持续增长。WBC 正负对照和 60 秒纹理运行通过。该阶段一次 MCP 截图发生 OOM，故障与恢复记录保留，不能算作全部截图成功。

证据：`evidence/review-fixes/2026-10-12/`。

<a id="nx5-screenshot-memory"></a>

## 截图 OOM 后的清理复验

2026-10-12，保持 `bccf6b9` 同一显示进程、SDK 和驱动不变。此前 tmpfs 共享内存 63792 KiB、空闲约 1200 KiB；`/run`、`/tmp` 占真实 RAM，不能当作随时可回收的普通磁盘缓存。

归档清理后 `/run` 43448 → 804 KiB，`/tmp` 约 15080 → 12372 KiB，MemAvailable 8236 → 53756 KiB。十次顺序截图通过，截图前最低可用内存约 47.2 MiB；RSS 高水位增量约 5060 KiB。此证据支持当次 OOM 与历史产物挤占内存有关，不证明任意并发截图安全。当前检查入口见 [MCP 内存检查](slint-mcp.md#截图前的内存检查)。

证据：`evidence/nx5-screenshot-memory/2026-10-12/`；原始 OOM 保留在上一阶段档案。
