# X9 性能与流水线分析

本篇合并 X9 早期富列表基线、旋转/写页优化以及流水线调查。设备为 Lombo N7 / Linux #452，物理 800×1280、顺时针 90°、逻辑 1280×800，同一字体和 100 项内容。CPU 为单核 100% 口径；FPS 计成功提交对应的 DRM 匹配完成事件。

显示契约与初始化问题见 [X9 接入报告](x9-framebuffer.md)，现行构建/运行见 [设备说明](../test-app/devices/x9/README.md)。后续批量纹理混合单独汇总在 [Slint 优化对照](slint-optimization.md#x9-texture-neon)，不与本篇阶段收益混算。

## 旋转分块与不透明写页

2026-10-14 至 15 日，`8604707` + Slint `ea7d0ae` → `cacf98f` + Slint `fa6a6d0`（showcase 07）。保持界面、分辨率和双页契约。32×32 分块改善旋转纹理源列访问；8×64 更慢，64×16 纵向略快但横向更慢，故采用两方向较均衡的 32×32。没有硬件 cache-miss 计数，局部性解释来自代码和受控比较。

不透明写页按整段检查 alpha，再批量换通道；动态页写入像素数不变。阶段中位数如下，后台等待与下一帧绘制重叠，不能简单相加预测 FPS。

| 阶段 | 纵向基线 → 优化 | 横向基线 → 优化 |
| --- | ---: | ---: |
| 绘制（含旋转） | 128.52 → **91.09 ms** | 79.92 → **59.66 ms** |
| framebuffer 写页 | 19.06 → **5.09 ms** | 11.83 → **3.17 ms** |
| 写入像素数 | 432,000 → 432,000 | 约 262,000 → 约 262,000 |
| 写页分段数 | 17 → 5 | 12 → 4 |
| PAN ioctl | 0.076 → 0.076 ms | 0.076 → 0.076 ms |
| 提交到匹配事件完成 | 8.48 → 8.06 ms | 8.22 → 8.78 ms |

正式无阶段探针结果：

| 场景 | 基线 FPS → 优化 FPS | 提升 | CPU 基线 → 优化（单核 100%） | RSS 基线 → 优化 |
| --- | ---: | ---: | ---: | ---: |
| 纵向连续滑动 | 6.64 → **10.21** | **53.7%** | 98.14% → 98.16% | 17.53 → 17.50 MiB |
| 横向连续滑动 | 10.73 → **15.55** | **44.9%** | 98.31% → 98.17% | 17.75 → 17.73 MiB |

纵向 P95 降为 110.33 ms；横向最大间隔增至 220.63 ms，因此不能声称消除了长尾。CPU 仍接近单核满载，收益为同样占用下更多完成帧。两张实际前台页与同字体、同旋转参考共 2,048,000 像素一致；不是逐扫描帧的无撕裂证明。证据：`evidence/x9-optimization/2026-10-14/`。

## 流水线边界与后续方向

2026-10-15 对同一 showcase 07 做只读源码、ELF 和设备核对；性能值仍来自上一轮，未运行新负载。当前时序详见 [平台说明](software-platform.md#事件循环) 和 [时序图](diagrams/runtime-sequence.html)：

- UI 线程执行输入/业务、Slint render、读取唯一保留画布并分段写物理后台页；render 与写页串行。
- `fb-present` 执行 PAN、DRM 匹配完成及模式复核，可与下一帧绘制重叠；成功确认后才改变页角色。
- 该版本写页已经有编译器生成的 NEON，已定位纹理循环仍是标量；后者已在后续 Slint 批量优化中处理，不能继续把它列为未实施项。

当时 render 约 91 / 60 ms，写页约 5 / 3 ms，完成等待约 8 ms 且已在后台。把写页移到第二核必须先获得不可变源；增加整帧复制可能抵消收益。直接 render 到物理后台页还可能破坏已隐藏的完成等待，因此不能只凭“少一次 copy”判断更快。

尚未验证的候选包括重复缩放/底图缓存、单帧独立区域并行。Slint renderer 的 Rc/RefCell 及同步 UI 访问不能直接跨线程共享；任何并行化须保留透明层叠、裁剪、缓存及脏区顺序。原调查没有按核/线程量化全部负载，也没有精确逐帧重叠测量或硬件 cache-miss 计数。证据：`evidence/x9-pipeline-neon/2026-10-15/`，为只读与反汇编记录，不是新性能成绩。
