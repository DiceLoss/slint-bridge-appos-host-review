# NX5 奇数坐标 TDE 混合优化

2026-10-14，实现 `b1164e4`，Slint `22804ff`，NX5 #233、SDK 字节不变。在[富内容列表调查](nx5-rich-list.md)已复现的奇数坐标整图回退基础上，修改 NX5 私有纹理准备和原生混合路径，保持现有界面、裁剪、双物理页与完成确认契约。

## 实现

源纹理按目标与源坐标的奇偶差预留 0 或 1 像素前缀，源步长对齐到 4 像素、高度对齐到 2 像素。目标混合矩形向内收缩到偶数边界，内部由 TDE 完成；每边最多 1 像素的边缘在硬件成功完成、目标缓存刷新后由 CPU 精确 source-over。不会放大裁剪或将应用坐标取偶数。极小且没有可用内部区域的矩形仍允许软件回退；透明目标、旋转和其他原有限制保留。

混合源缓存增加位置奇偶相位，避免错误复用另一种前缀；完全不透明复制不受位置相位限制。两个源 MMZ 槽增加余量，目标画布分配不变。未知 DMA 完成状态依旧隔离，禁止补写 CPU 边缘或按成功帧提交。详细运行顺序与缓存规则集中在[平台说明](software-platform.md)。

## 正确性验证

主机先用生产 `native.c` 和 SDK 替身复现旧实现返回 Unsupported，再通过 256 组源/目标坐标、裁剪尺寸奇偶、两种 alpha 表示及整体透明度组合的逐像素对照。替身核对所有硬件混合矩形均满足偶数要求，并检查矩形外保护区；另外覆盖离散多矩形、未知完成时边缘不得改写及缓存相位变化。原生故障注入、转换边界、ASan/UBSan、feature 矩阵、格式、严格 Clippy 和 ARM release 构建通过。

独占运行实机 `nx5_hardware_compare` 与双页回归：奇数 x/y、负坐标裁剪、右下裁剪、奇数位置整体透明度、完全不透明复制、80 帧增量移动及 1024×600 全幅源 padding 均通过；硬件与软件最大通道差不超过 1，不透明路径精确一致。双页回归另比较 100 帧真实 TDE / 内存页。两次最终测试正常退出，VO 关闭，MMZ 回到 4900 KiB / 2 块。

首次实机对照的右下测试坐标按全屏尺寸设置，却用于 512×384 测试画布，未触发绘制；修正测试几何，并将全幅 padding 用例放到旧缓冲释放后的独立 1024×600 画布中复验。首次失败日志保留，没有修改生产实现来绕过测试。

原始证据位于本地忽略目录 `evidence/nx5-odd-blend/2026-10-14/`，需另行取得；最终硬件结果使用 `hardware/compare-02.*` 和 `hardware/pages.*`，首次 `compare.*` 不计作通过。

## 应用检查与测量方法

优化版横纵两方向均遍历全部 100 个稳定 ID，宽幅拖动、锁定轴、拖动不误选、首末端夹紧及项目选择通过，六张受内存保护的实机原生截图完成。第一次主机调用受沙箱网络限制，没有向 MCP 发出有效请求；重试使用同一个有限应用进程，完整结果保存于 `ui-full-02/`。

性能与旧版 `8d6bd47` 使用同一个启动 ID `4aa4f5d2-8de2-42cb-9c2b-44c3e74d6e2b`、相同界面、字体、SDK 与原生 MCP 手势流程。每个方向先预热至少 8 秒；CPU/RSS 在独立无 trace 进程中采样至少 45 秒，FPS 在另一个进程中采样至少 90 秒，仅使用阶段内完整 150 次成功 PAN 批次，丢弃跨阶段的首批。每次手势核对实际位移，避开列表端点。CPU 为单核百分比，RSS 为进程驻留内存；保留的部署文件另占 tmpfs，不算入 RSS。

这是一轮同场景顺序对照，未做多轮随机化误差估计；原生 MCP 的查询、插值和等待属于负载。硬件调用数按绘制帧统计，完成提交帧率按成功 PAN 统计，二者窗口分别记录。板端仍没有经验证的累计 TDE busy% 指标，缓存命中率也不是硬件忙碌率。

TDE 混合量纵向约为旧版 2.42 倍、横向约 2.02 倍，两个方向错误均为 0。纵向完整绘制计数窗口为 1050 帧，复制 0.98、混合 3.02、软件纹理回调 179.11 次/帧；横向为 900 帧，复制 0.99、混合 3.27、软件纹理回调 221.40 次/帧。成功硬件纹理调用中的源缓存命中率分别为 27.99% / 30.55%；比旧版降低，因为新增奇数位置硬件调用也需要相应相位的源准备，不能解释成硬件利用率下降。

本轮解决了奇数坐标触发整张大纹理软件回退的问题，但端到端帧率只小幅变化：纵向约 +1.19%，横向约 +0.16%，横向变化处于本轮批次波动范围内。文字、小纹理、源准备及其他页面工作仍存在；本轮未分项计时，不据此声称已定位剩余瓶颈。性能原始窗口见 `*-resources/`、`*-fps/`，汇总见 `results.json` 和 `tde-counters.json`。
